# deez.run v0.1.0

First explicit production baseline for the hosted Deez web application.

## Included

- public `.nut` catalog, search, author pages, immutable registry pins, and production SEO/security handling;
- magic-link accounts with canonical account convergence and private cloud-backed libraries;
- SolidJS 2 + StyleX SPA served by the compiled Deez Zig server on Fly.io;
- local-first IndexedDB cache with durable outbox replication and explicit offline hydration;
- cross-device deck visibility and review convergence;
- safe card rendering and route-scoped WebAssembly CSP for Study;
- GTA/neo-retro signed-in application shell and responsive mobile navigation;
- large-deck performance fixes for deck summaries and first-card Study latency;
- atomic/observable portable imports with chunked replication, malformed-note isolation, and 1,200-note regression coverage;
- bulk deck snapshot hydration instead of the normal per-card N+1 path;
- Study session progress, due/new/learning counters, keyboard controls, undo-last-review, and completion state;
- deck rename, duplicate, `.nut` export, scheduling reset, and confirmed deletion;
- explicit CI latency/query-shape budgets plus complete production Docker/WASM/API/PWA smoke coverage.
