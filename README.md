# deez.run

Public discovery and distribution catalog for shareable Deez `.nut` decks.

This repository is intentionally separate from the local Deez core, local web UI, and desktop shell.

## Scope

The first milestone is a public, GitHub-backed catalog that can search registered nuts, show safe deck previews and metadata, and link to checksum-pinned `.nut` downloads from their source repositories.

See `docs/architecture.md` once the catalog foundation lands.
